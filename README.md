# Abdullah Ayman — Frontend Engineer Portfolio

A modern, high-performance, and fully responsive personal portfolio website built with **React.js**, **Vite**, and **Tailwind CSS**.


## ✨ Key Features
- **Modern Dark UI:** Sleek, accessible dark-themed interface designed with Tailwind CSS.
- **Fully Responsive:** Seamless layout optimization across Desktop, Tablet, and Mobile devices.
- **Featured Projects:** Detailed breakdown of key projects, highlighting technologies, features, and source code.
- **Interactive Contact:** Built-in contact form and direct links to social platforms and email.

## 🛠️ Tech Stack
- **Core:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide Icons / SVGs
- **Deployment:** Vercel
